# Bundled fonts

| File | Family | License | Use |
| --- | --- | --- | --- |
| `Inter-Regular.woff2` | Inter 400 | OFL-1.1 | Preview body text |
| `Inter-Medium.woff2` | Inter 500 | OFL-1.1 | Preview labels and controls |
| `Inter-SemiBold.woff2` | Inter 600 | OFL-1.1 | Preview emphasis |
| `Fraunces-Variable.woff2` | Fraunces, variable | OFL-1.1 | Preview display text |
| `../android-res/font/inter_variable.ttf` | Inter, variable | OFL-1.1 | Castela apps and launcher |
| `../android-res/font/fraunces_variable.ttf` | Fraunces, variable | OFL-1.1 | Castela apps and launcher |

The system font is **not** replaced. These files are used only inside Castela
apps, the launcher, and the local preview.

Source: the upstream Inter and Fraunces repositories, retrieved 2026-11-08.
License texts are in `OFL-Inter.txt` and `OFL-Fraunces.txt`. Do not rename a
reserved font name as part of a modification without following the OFL rules.
