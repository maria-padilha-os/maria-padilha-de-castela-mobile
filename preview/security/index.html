Boundaries this panel keeps

  • No automatic scan, background timer, worker, or hidden service
  • No root, raw sockets, privileged permissions, or kernel claims
  • No upload, telemetry, or remote font, image, or script
  • Stop and clear revokes the session and removes session results

This is a front-end contract on stock GrapheneOS. A future signed app build must use public Android APIs and keep the same separation from general settings. See docs/security-panel.md.
